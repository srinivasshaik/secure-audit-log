# Engineering Documentation

This directory holds the evidence and decisions required to make the engineering work reviewable.

- `architecture/` — system design, data model, API design, and trade-offs
- `scenarios/` — requirement decomposition and scope for scenarios A, B, and C
- `decisions/` — architecture decision records
- `validation/` — testing strategy, quality gates, and risk controls
- `delivery/` — final engineering summary and submission checklist
